# 智谱AI知识库检索示例

## 功能说明

本示例展示了如何使用智谱AI的托管知识库功能进行文档检索，并提供替代方案。

### 主要功能

1. **托管知识库方案**
   - 创建知识库
   - 上传 FAQ 文档
   - 等待文档向量化完成
   - 检索指定问题
   - 自动清理资源

2. **替代方案**
   - 当托管知识库不可用时自动启用
   - 基于关键词匹配的文本检索
   - 无需创建知识库，直接分析文档内容

## 使用方法

### 1. 设置 API Key

```bash
export ZHIPUAI_API_KEY='your-api-key'
```

### 2. 运行脚本

```bash
cd outputs
python3 main.py
```

### 3. 运行测试（不依赖API）

```bash
python3 test_logic.py
```

## 文件结构

```
outputs/
├── main.py          # 主脚本
├── test_logic.py    # 逻辑测试脚本
└── README.md        # 说明文档
```

## 工作流程

1. **尝试托管知识库**
   - 创建知识库
   - 上传 faq.txt 文档
   - 等待向量化完成
   - 执行检索

2. **失败时使用替代方案**
   - 直接读取文档
   - 关键词匹配
   - 返回相关片段

## 注意事项

- 需要有效的智谱AI API Key
- 托管知识库可能有文档损坏或向量化失败的情况
- 替代方案基于简单关键词匹配，不如向量检索准确
- 脚本会自动清理临时资源

## 预期输出

成功时显示类似内容：

```

1. [相似度: 0.832] 购买商品后7天内，可申请无理由退货
--------------------------------------------------
2. [相似度: 0.756] 退换货政策自签收之日起计算有效期
--------------------------------------------------
```

如遇托管知识库问题，会自动切换到替代方案显示：

```

1. [匹配度: 10] 1. 退换货政策的有效期
   - 购买商品后7天内，可申请无理由退货
   ...
```
