# 2026年中国新能源汽车出口市场简报生成器

这个脚本使用智谱GLM-5.3模型生成关于2026年中国新能源汽车出口的市场分析简报。

## 使用方法

1. 设置API Key：
   ```bash
   export ZHIPUAI_API_KEY=your_api_key_here
   ```

2. 运行脚本：
   ```bash
   python3 main.py
   ```

## 功能特点

- 自动生成不少于600字的市场简报
- 包含多个小标题和具体数据
- 内容完整连贯，结构清晰
- 自动验证字数和内容完整性
- 适合直接放进周报使用

## 输出说明

脚本会：
1. 显示生成进度
2. 打印完整的市场简报
3. 显示字数统计
4. 确认内容是否达标

- 需要有效的智谱AI API Key
- 确保网络连接正常
