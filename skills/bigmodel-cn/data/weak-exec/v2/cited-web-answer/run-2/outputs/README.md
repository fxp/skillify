# 联网问答小工具

这是一个使用智谱 AI GLM 模型的联网搜索功能实现的问答工具。

## 功能特点

- 自动回答固定问题：「2026 年智谱 BigModel 发布了哪些新模型」
- 使用智谱 AI 的联网搜索功能获取最新信息
- 自动显示回答内容下方的信息来源
- 每个来源包含标题和可点击的 URL
- 通过环境变量读取 API Key

## 使用方法

1. 设置环境变量：
```bash
export ZHIPUAI_API_KEY="your_api_key_here"
```

2. 运行脚本：
```bash
python3 main.py
```

## 脚本说明

- 使用模型：glm-5.3（支持工具调用的旗舰模型）
- 搜索引擎：search_pro_bing（确保返回可点击的真实链接）
- 搜索结果数量：10 条
- 输出格式：回答内容 + 信息来源列表

## 注意事项

- 需要有效的智谱 AI API Key
- 需要网络连接以调用 API 和进行搜索
- 脚本已验证可以正常编译（python3 -m py_compile）
