# 联网问答小工具

这是一个使用智谱AI开放平台API实现的联网问答小工具，可以查询"2026年智谱BigModel发布了哪些新模型"并显示信息来源。

## 功能特点

- 使用智谱AI的GLM-5.3模型
- 自动调用联网搜索功能获取最新信息
- 显示回答内容及可点击的信息来源链接
- 从环境变量读取API Key，安全可靠

## 使用方法

1. 设置环境变量：
```bash
export ZHIPUAI_API_KEY="your_api_key_here"
```

2. 运行脚本：
```bash
python3 main.py
```

## 脚本说明

脚本会自动：
- 提问"2026年智谱BigModel发布了哪些新模型"
- 使用Bing搜索引擎搜索相关信息
- 显示模型的详细回答
- 列出所有信息来源，包括标题、来源媒体、发布时间和可点击的链接

## 注意事项

- 确保已设置有效的ZHIPUAI_API_KEY环境变量
- 需要网络连接才能访问智谱AI API和进行联网搜索
- 脚本使用了`search_pro_bing`搜索引擎以确保返回可点击的链接
