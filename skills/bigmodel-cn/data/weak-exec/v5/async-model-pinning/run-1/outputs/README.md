# 异步情感分类脚本

这个脚本使用智谱AI的异步接口对三句话进行情感分类，并严格检查模型版本的一致性。

## 功能特点

- 使用 `async/chat/completions` 接口提交异步任务
- 通过轮询 `async-result/{task_id}` 获取结果
- 对三句话进行情感分类
- 严格锁定模型版本为 `glm-4.6`
- 打印"请求的模型"和"实际使用的模型"进行审计
- 当模型不一致时明确报警

## 使用方法

1. 设置环境变量：
```bash
export ZHIPUAI_API_KEY="your_api_key_here"
```

2. 运行脚本：
```bash
python3 main.py
```

## 脚本功能说明

### 三句测试文本
1. "今天天气真好，心情很愉快！"（正面情感）
2. "这份报告的数据完全不对，让我很失望。"（负面情感）
3. "不知道该说什么，就这样吧。"（中性情感）

### 审计功能
- 每个任务都会打印请求的模型（glm-4.6）和接口实际使用的模型
- 最终汇总时会检查所有请求的模型与实际使用是否一致
- 发现不一致时会明确报警显示

### 异步处理流程
1. 提交异步任务并获取 task_id
2. 每2秒轮询一次任务状态
3. 最多等待60秒，超时则抛出异常
4. 解析返回的JSON结果并提取情感分析信息
