# 情感分类脚本使用说明

## 功能
使用智谱 GLM API 对文本进行情感分类，输出严格符合数据库要求的格式。

## 输出格式
每个文本的分析结果严格遵循以下格式：
```json
{
    "sentiment": "正面"/"负面"/"中性",
    "score": 0到1之间的数字
}
```

## 使用方法

1. 设置环境变量：
```bash
export ZHIPUAI_API_KEY="your_api_key_here"
```

2. 运行脚本：
```bash
python3 main.py
```

## 特点
- 使用 `glm-4.6` 模型，适合文本分类任务
- 通过 `response_format: {"type": "json_object}" 确保输出 JSON 格式
- 实现了客户端校验和重试机制（最多3次）
- 严格按照要求的字段名和取值输出
- 包含置信度评分（0-1之间）
- 输出可直接入库，符合数据库约束
