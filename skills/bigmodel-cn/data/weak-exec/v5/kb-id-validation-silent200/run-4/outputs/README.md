# 知识库ID校验脚本使用说明

## 功能
校验智谱AI托管知识库ID是否存在且可用，作为发布流水线的卡点检查。

## 使用方法

### 1. 设置环境变量
```bash
export ZHIPUAI_API_KEY="your_api_key_here"
export ZHIPU_KB_ID="your_knowledge_base_id_here"
```

### 2. 运行脚本
```bash
python3 main.py
```

## 返回码
- 0：知识库有效（通过）
- 1：知识库无效（失败）

## 重要说明

1. **严格校验**：本脚本采用保守策略，宁可误报无效，绝不放行无效ID
2. **API兼容**：使用官方知识库详情接口 (`/llm-application/open/knowledge/{id}`)
3. **双重校验**：不仅检查HTTP状态码，还检查响应体中的`code`字段
4. **安全设计**：API Key在输出中会被部分隐藏
5. **超时保护**：设置了30秒超时，避免长时间等待

## 在CI/CD中使用

可以在Jenkins/GitLab CI等工具中使用：

```yaml
# GitLab CI示例
validate_knowledge_base:
  script:
    - export ZHIPUAI_API_KEY=$ZHIPUAI_API_KEY
    - export ZHIPU_KB_ID=$ZHIPU_KB_ID
    - python3 main.py
  allow_failure: false  # 关闭允许失败，确保无效ID无法上线
```

## 注意事项

1. 确保环境变量设置正确
2. 确保网络能够访问智谱AI的API服务器
3. 脚本只验证知识库本身是否存在，不验证库内文档的向量化状态
4. 如果遇到网络问题，建议检查防火墙设置
