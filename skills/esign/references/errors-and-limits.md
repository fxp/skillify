## 1. 先分清四种响应形状

| 来源 | 形状 | 判断 |
| --- | --- | --- |
| 业务接口 | `{"code": 0, "message": "成功", "data": {...}}` | `code == 0`（int）成功；非 0 失败，按 code 分支，不按 message |
| API 网关鉴权 | HTTP 401，`{"success": false, "code": 401, "message": "…"}` | 见 §2；**没有 data** |
| OAuth 换 token | HTTP 200，`{"code": 72000032, "message": "应用停用或应用不存在", "data": null}`（探测证实） | 同业务接口 |
| OSS 文件上传（PUT） | 成功 `{"errCode": 0, "msg": "成功"}`；失败是 OSS 的 HTTP 400/403/405 | 字段名是 `errCode`，见 [files-and-templates.md §3](files-and-templates.md) |

错误文案里的 `%s` 是占位符，会被替换成具体参数值。

## 2. 网关鉴权错误（HTTP 401 / 403）

| code | message | 原因与处理（401 排查页原文；标“探测”的已无凭证复现） |
| --- | --- | --- |
| 401 | 缺少参数 | 签名模式缺 `X-Tsign-Open-Ca-Timestamp` / `X-Tsign-Open-Ca-Signature` / `X-Tsign-Open-App-Id` 之一 |
| 401 | AUTHSTRATEGY_NOT_FOUND | `X-Tsign-Open-Auth-Mode` 值不对（签名模式只能是 `Signature`） |
| 401 | 无效的应用 | appId 错、appId 与域名环境不匹配（正式 appId 调了沙箱域名或反之）、应用被停用。**探测**：伪造 appId 在沙箱和正式都返回它；不存在的路径、过期时间戳在伪造 appId 下也返回它 |
| 401 | TOKEN错误 | token 模式下 token 不属于该应用或已过期 / 被新 token 顶掉 |
| 401 | TOKEN_CANT_BE_NULL | token 模式下没传 `X-Tsign-Open-Token`。**探测**：签名模式漏传 `X-Tsign-Open-Auth-Mode` 也是这个（网关默认按 token 模式） |
| 401 | INVALID_TIMESTAMP | 时间戳不是 15 分钟内的**毫秒**值；常见于服务器时区 / 时钟不对或传了秒 |
| 401 | INVALID_SIGNATURE | 签名算错：secret 与 appId / 环境不匹配或带空格；算 MD5 的 JSON 与发送的 JSON 不一致；签名串里 Accept / Content-Type / Content-MD5 与请求头不一致；Path 带了域名；query 没排序；query 中文在签名串里被编码了 |
| 401 | SIMPLE_MODE_CANT_PASS | 错误码页列出，⚠ 原因文档未说明 |
| 403 | IP白名单不匹配 | 调用方公网出口 IP 不在应用白名单里；2026-07-31 起白名单不能再填 `*` |

`INVALID_SIGNATURE` 自查顺序：打印你的 StringToSign（把 `\n` 显示出来）→ 对照 [auth-and-signing.md §4](auth-and-signing.md) 逐行检查 →
用 `sign_check` 式的本地向量确认 HMAC / Base64 实现 → 再用官方《鉴权签名计算》工具对照。

## 6. 限制与配额速查

| 项 | 限制 | 出处 |
| --- | --- | --- |
| 请求时间戳 | 15 分钟内，毫秒 | 公共请求头 |
| OAuth token | 120 分钟；重新获取后旧 token 仅剩 5 分钟 | OAuthToken 页 |
| 上传文件 | 单文件 ≤50MB，单页 ≤20MB；文件名 ≤100 字符 | 上传本地文件 |
| 上传地址 `fileUploadUrl` | 60 分钟有效 | 上传本地文件 |
| 文件状态轮询 | 每 3 秒，总计 ≤90 秒（建议值） | 查询文件上传状态 |
| 单流程文件 | ≤50 个，总计 ≤500MB | 基于文件发起签署 |
| 签署方 | 一次创建 ≤10 个，全流程 ≤50 个 | 同上 |
| 签署区 | 全流程 ≤300 个 | 同上 |
| 签署截止时间 | 默认 90 天，最长 90 天；延期只能 1 次 | 同上 / 错误码 |
| signOrder | 1–255 | 同上 |
| 签署短链接 / 长链接 | 90 天 / 永久 | 获取签署页面链接 |
| 认证授权链接 | 30 天 | 认证授权链接 |
| 模板制作链接 | 24 小时 | 获取制作合同模板页面 |
| 下载链接 | 1–3600 秒，默认 3600 | 下载已签署文件 |
| 催签 | 发起后 30 分钟内不能催，之后每 10 分钟 1 次 | 错误码 |
| 流程列表 | pageSize 1–100；时间区间 ≤1 年；只能查近 5 年 | 查询签署流程列表 |
| 模板列表 | pageSize ≤20 | 查询合同模板列表 |
| 关键字检索 | 一次 ≤30 个关键字 | 检索文件关键字坐标 |
| HTML 动态模板 | 填充表格 ≤2000 行 | 填写模板生成文件 |
| 撤销原因 | ≤50 字 | 撤销签署流程 |
| 回调 | 5 秒内响应（建议）；失败最多重试 16 次 | 回调通知 |
| QPS / 频率限制 | ⚠ 抓取的页面没有给出数值；正式环境禁止压测 | — |

## 7. 重试策略建议

| 情况 | 是否重试 | 做法 |
| --- | --- | --- |
| 网络超时 / 连接失败、`1435012 服务异常`、`1430012 服务异常` | 可以 | 指数退避，最多 3 次；**创建类接口（create-by-file 等）重试前先查是否已创建成功**，避免重复发起 |
| `1437513 文档未成功转换成pdf` | 可以 | 回到文件状态轮询，等 fileStatus=2/5 再发起 |
| `401 INVALID_TIMESTAMP` | 修时钟后重试 | 服务器 NTP 校时，时间戳用毫秒 |
| `401 INVALID_SIGNATURE` / `无效的应用` / `403 IP白名单不匹配` | 不要重试 | 配置或代码问题 |
| `1435002` 参数错误、`1436116` 未授权、`1435404/1435405` 份数不足 | 不要重试 | 修参数 / 拿授权 / 充值 |
| `1437137/1437138` 催签过频 | 延后 | 按 30 分钟 / 10 分钟规则 |
| OAuth 模式 `TOKEN错误` | 重新获取一次 token 后重试 1 次 | 注意集中管理 token |
