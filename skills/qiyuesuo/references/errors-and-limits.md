## 1. 先判断成功还是失败

- 成功：`code == 0`（「接口响应码说明」`0 [SUCCESS]`）或 `responseCode == "00000000"`（模板列表等页 `00000000 SUCCESS`）。两种写法都在文档里出现，判断时两个都认（[auth-and-signing.md](auth-and-signing.md) §8）。
- 失败：**先解析 JSON 再看 HTTP 状态**。无凭证探测（2026-09-11）：错误响应的 HTTP 状态码等于 `code`（441、442），不是 200 也不是标准 401。
- 下载类接口成功时返回文件流；失败格式 ⚠ 文档未说明，按 `Content-Type` 分支。
- 日志里同时记 `code`、`responseCode`、`message`，找契约锁排查时要用。

## 2. 鉴权类错误（无凭证探测）

以下均为无凭证探测（2026-09-11）结果，每条复跑两次一致，完整命令见 `qiyuesuo-workspace/probe-log.md`：

| 场景 | HTTP | 响应体 |
| --- | --- | --- |
| 不带任何 `x-qys-open-*` 头 | 441 | `{"message":"HEADER REQUIRED,x-qys-open-accesstoken","code":441,"responseCode":"11990441"}` |
| AppToken 无效（测试 / 正式环境相同） | 442 | `{"message":"INVALID TOKEN","code":442,"responseCode":"11990442"}` |
| AppToken 无效 + 不存在的路径 | 442 | 同上（token 校验先于路由，不会返回 404） |
| AppToken 无效 + 缺 nonce 头 | 442 | 同上（先报 token，无法据此判断 nonce 是否必填） |
| AppToken 无效 + 时间戳早 20 分钟 | 442 | 同上 |

<!-- Gap: 文档「接口响应码说明」全局码只有 0/1001/1002/1005/1601，各接口页的响应码表也没有鉴权类错误；无凭证探测（2026-09-11，复跑一致）缺鉴权头返回 HTTP 441 + code 441 / responseCode 11990441，无效 token 返回 HTTP 442 + code 442 / responseCode 11990442。 -->

处理：

- `441 HEADER REQUIRED,<header>`：message 里带着缺的头名，检查拼写（全小写 `x-qys-open-accesstoken` 等）和是否被代理 / 网关剥掉。
- `442 INVALID TOKEN`：AppToken 不对、用错环境（测试 token 调正式地址或反之），或应用未审核通过。**重试无效**。
- 签名错误、nonce 重复、时间戳过期、IP 不在白名单时的错误码 ⚠ 文档未说明、也无法无凭证测出（见 verification-plan #4、#5、#7）。

## 3. 两套响应码：4 位与 8 位

文档里同一类错误有两种写法：

| 4 位写法（「接口响应码说明」、签署合同汇总页、认证页） | 8 位写法（新版接口页"响应码"表） | 含义 |
| --- | --- | --- |
| `1101 INVALID CONTRACT STATUS` | `11011101` | 合同状态无效 |
| `1102 DUPLICATE SIGNATORY` | `11011102` | 重复的签署方 |
| `1106 INVALID STAMPER TYPE` | `11011106` | 签章类型无效 |
| `1107 NOT SIGN STEP` | `11011107` | 未轮到签署 |
| `1109 SIGN PAGE BEYOND` | `11011109` | 签署页码超出 |
| `1201 SEAL NOT FOUND` | `11011201` | 找不到印章 |
| `1203 INVALID SEAL STATUS` | `11011203` | 印章状态无效 |
| `1701 EMPLOYEE NOT FOUND` | `11041701` | 找不到员工 |
| `1702 EMPLOYEE DISMISSED` | `11041702` | 员工已离职 |
| `1705 EMPLOYEE NOT REGISTE` | `11041705` | 员工未注册 |
| `1005 INVALID PARAM` | `11990005` | 参数无效 |
| `1001 ERROR` | `21990001` | 服务器内部错误（找不到对应开放平台错误码时统一返回） |
| `1002 PERMISSION DENIED` | `14990002` | 没有接口调用权限 / 权限不匹配 |

- 对照可见 8 位码的末几位与 4 位码一致（如 `11011101` ↔ `1101`、`11041701` ↔ `1701`），探测到的 `11990442` ↔ `code 442` 也是这个形态。⚠ 文档未说明两套码的关系和实际返回哪一套；代码里**按 `message` + 两个字段一起记日志**，业务分支优先用 `responseCode`，同时兼容 4 位 `code`。
- 同一错误在不同页有不同 8 位码：公司不存在 `11041801`（多数页）vs `11041805`（模板详情页）；合同不存在 `11101003` vs `11011126`（撤回 / 作废页）vs `3004`（未知签署方链接页）。⚠ 文档自相矛盾。

## 4. 按场景查错误码

### 全局（「接口响应码说明」第 5 节）
`0` 成功；`1001` 服务器内部错误；`1002` 没有接口调用权限（联系客服开通）；`1005` 参数无效；`1601 INSUFFICIENT BALANCE` 余额不足（打款充值或联系管理员；测试环境找客服充值）。

### 创建合同草稿
| 码 | 含义 / 处理（文档原文） |
| --- | --- |
| `1101` | 合同状态无效：已发起的合同不能再建成草稿 |
| `1102` / `11011102` | 签署方重复 |
| `1103` | 缺 action：公司签署方要传签署动作，或使用业务分类的签署流程 |
| `1105` | 审批节点缺操作人 |
| `1111` | 缺经办人：签署流程有经办人环节，要给签署方传 `receiver` |
| `1113` | 缺签署方（`signatories` 为空） |
| `1116` | 发起方没填完模板必填参数（按返回的参数名补） |
| `1201` / `1203` | 印章 ID 不存在 / 印章不是正常状态 |
| `1301` | 签署方与业务分类预设的顺序 / 数量不一致 |
| `1401` | `send: true` 但合同没有文档 |
| `1701` / `1702` / `1705` | `receiver` 或 `creator` 不是员工 / 已离职 / 未注册 |
| `11011151` | 没有该业务分类的发起权限 |

### 添加合同文档 / 发起合同
`1101`（只能给草稿加文档、只能发起草稿）；`1403 INVALID FILE`（文件损坏或类型不对）；`1402 UNSUPPORTED FILE TYPE`（不支持的类型或与声明类型不符）；`1108 KEYWORD NOT FOUND`（关键字没找到，检查 `keywordIndex`）；`1109`（没设关键字时 `page` 超出页数）；`1203`；`1116`；`11990010 UPLOAD FILE OVERSIZE`。

### 签署
`1106`（公章只能 `COMPANY` / `TIMESTAMP` / `ACROSS_PAGE`；法人章只能 `LP` / `TIMESTAMP`）；`1107` / `11011107`（未轮到或没有该节点）；`1109`；`1201`（找不到印章 / 法人章 / 个人签名）；`11011121`（用户没有合同操作权限）。

### 页面链接
`1110 NO VIEW PERMISSION`（签署页面：`user` 不是当前签署方）；`1401`（浏览页面：草稿还没有文档）；`1101`（短链接：草稿不能获取）；`1125` / `1113`（未知个人签署方链接：没有待加入的签署方）。

### 撤回 / 作废
`1101`：状态不支持。支持的状态与动作：`DRAFT` 删除；`FILLING` / `SIGNING` 撤回；`COMPLETE` 发起作废并签署发起方。

### 员工 / 印章 / 认证 / 业务分类
| 码 | 含义 |
| --- | --- |
| `1703` / `11041703` | 员工已认证时传入的姓名与实名不符（另一页把 `11041703` 写成"操作人未注册"，⚠ 文档自相矛盾） |
| `11041802` | 无该公司权限：仅支持对接方及其子公司 |
| `11011204` / `11011205` | 已存在法人章 / 已有待审批的法人章 |
| `11011207` | 印章使用者不可为空 |
| `12072210` | 印章自动生成失败 |
| `1604` | 个人认证 authId 未匹配 |
| `1605` | 该公司已完成企业认证 |
| `11011304` | 业务分类配置不允许（如发起后不允许添加签署方） |
| `11990011` | 参数长度超过限制 |

## 5. 常见报错与处理（FAQ）

| 现象 | 原因与处理（FAQ 原文） |
| --- | --- |
| 签公章 / 法人章报 "this contract is not turn to sign or has bean signed" | 合同未发起或已完成；合同里没有调用方的公章 / 法人章节点；或前面有经办人签字节点还没签（经办人只能在页面签） |
| 发起报"用户认证信息与合同经办人信息不匹配：XX" | 接收方手机号已实名，但传入的姓名与实名不一致 |
| 测试环境余额 0.00 无法发起 | 联系客服充值 |
| 用模板建合同报"没有使用模板的权限 / 模板Id无效" | 用了开放平台控制台的旧模板；新接口只认云平台「文件 → 文件模板」里的模板 ID |
| 接口建的草稿在云平台看不到 | 草稿只有创建人能看，建草稿时传 `creator` |
| 认证链接没打开就失效 | 链接被 QQ / 微信等聊天软件后台预打开过；认证链接只能打开一次 |
| 开了短信通知却没收到 | 顺序签署时只有轮到的节点才发；当前操作人自己不收；账号在登录状态不发 |
| 签章位置跑偏 | Word 转 PDF 排版变化；改用关键字定位 |
| PDF 阅读器里签名显示"未验证" | 公有云用的是事件型证书，根证书不在 PDF 默认信任列表，需要手动信任根证书 |

## 6. 频次限制、有效期与大小上限

**频次限制（各接口页"频次限制"一节原文）**

| 接口 | 规则 |
| --- | --- |
| 下载合同文档 `/v2/document/download`、下载合同与附属文件 `/v2/contract/download` | 同一合同文档两次下载间隔在 25 分钟内、连续 10 次后锁定 12 小时，锁定时间叠加 |
| 下载合同附件 `/v2/attachment/download` | 同一附件同上规则 |
| 编辑印章 `/v2/seal/edit` | 同一请求 1 小时内连续 5 次后锁定 18 小时，叠加 |
| 添加员工 `/v2/employee/create` | 同一请求 1 小时内连续 5 次后锁定 6 小时，叠加 |
| 抄送合同 `/v2/contract/copysend` | 响应码表里有 `11990006 接口调用频繁`（阈值未写） |

⚠ 文档未说明：通用 QPS / 日调用量限制；被锁定时返回哪个错误码。

**有效期与时限（文档原文）**

| 对象 | 时限 |
| --- | --- |
| nonce | 10 分钟内不能重复 |
| 签署页面 `pageurl`、预签署页面 `appointurl` | 默认 30 分钟；`expireTime` + `expireTimeUnit` 可设 5 分钟 – 90 天（FAQ 另说 10 分钟，⚠） |
| 浏览页面 `viewurl` | 30 分钟 |
| 合同与附属文件下载链接 `downloadurl` | 60 分钟 |
| 个人认证链接 | 只能打开一次；未打开 5 分钟失效；打开后会话 15 分钟 |
| 合同截止签署时间 `expireTime` | 距发起不能超过 2 年（超过自动改为 2 年）；延期后同样 ≤ 2 年 |
| 作废截止日期 | 3 年以内；到期未完成作废，文件恢复"已完成" |
| 草稿 | 超过 1 年不发起自动删除 |
| 短信签署链接 | 不过期，但受合同截止签署时间约束（FAQ） |

**大小上限**：单个合同文件 ≤ 50MB（`addbyfile`）；多文件合并总大小 ≤ 50M（`addbyfiles`）；模板普通文本参数 ≤ 1000 字；`relatedContractIds` ≤ 50 个；`corpSealIds` ≤ 9 个。

## 7. 重试策略建议

以下是基于上文的建议，不是文档要求：

| 情况 | 建议 |
| --- | --- |
| 441 / 442 / 1002 / 14990002 | 配置或权限问题，不重试，告警 |
| 1005 / 11990005 / 1101 / 1107 / 1301 等业务码 | 不重试；按 message 修参数或等流程推进（例如 1107 等回调通知轮到后再签） |
| 1001 / 21990001、网络超时、5xx | 指数退避重试 2–3 次；**每次重试重新生成 timestamp + nonce + signature** |
| 创建草稿超时不知道成没成功 | 带同一个 `bizId` 重试（草稿态会覆盖而不是重复创建），或先按 bizId 查详情 |
| 下载接口 | 成功后落盘，不要重试同一文档超过频次规则 |

## 8. 注意事项与 ⚠

- ⚠ 文档自相矛盾：4 位 / 8 位两套码（§3）；同一错误多个 8 位码（§3）；`11041703` 两种含义（§4）；签署链接 30 vs 10 分钟（§6）。
- ⚠ 文档未说明：签名错误 / nonce 重复 / 时间戳过期 / IP 白名单拒绝的错误码（§2）；通用 QPS 限制与锁定后的错误码（§6）；下载失败的响应格式（§1）。
- 鉴权错误 441 / 442 的形态来自无凭证探测，带真实凭证时的其他错误码以真实返回为准。
